# Cas d’usage NIHAO (Phase 6)

## 1. Commercial — Pack CRM + Sales

Une PME B2B centralise leads et opportunités dans le CRM, génère devis depuis Ventes, et valide les propositions agents via AI Office (approbation CEO). Le chat agents accélère le brief commercial sans sortir du workspace.

## 2. Ops — Pack WMS + PIM

L’équipe logistique suit inventaire et mouvements (WMS) tout en maintenant le référentiel produits / variantes (PIM). Les alertes stock passent par l’agent Stock ; le BI consolide comptes PIM et runs runtime.

## 3. Agents — Pack Studio + Marketplace

Un responsable process définit un graphe agent dans le Studio, le publie en marketplace privé, et l’installe pour les équipes. Le runtime exécute le graphe avec reprise humaine ; la gouvernance trace guardrails et sandbox outils.
